## 🎯 Project Objectives
This project solves critical retail business problems by delivering across four main phases:
1. **Dashboard Creation:** Designing a visually polished, intuitive user interface featuring cross-filtering and granular parameter exploration.
2. **Data Analysis:** Extracting valuable commercial trends and insights to measure sales campaign effectiveness.
3. **Sales Forecasting:** Leveraging historical data to build accurate 15-day time-series projections.
4. **Actionable Recommendations:** Providing data-backed operational steps to improve supermarket growth, efficiency, and customer satisfaction.

---

## 🛠️ Architecture & Tech Stack
* **Frontend Layer:** Power BI Desktop (Interactive Visualization Dashboard & Slicers)
* **Backend Layer:** Supermarket Transactional Dataset (Cleaned via Power Query Engine)
* **Analytical Engines:** Power BI Time-Series Exponential Smoothing Forecasting Model
